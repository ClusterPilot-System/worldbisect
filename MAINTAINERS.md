# Maintainers

## Active maintainers

- `@JossefMo1` — project lead and release maintainer

## Responsibilities

Maintainers review security boundaries, proof semantics, public contracts, release artifacts, and contributor provenance. Release authority includes responsibility for deterministic builds, checksums, SBOM publication, artifact attestation, and security-response coordination.

## Adding or removing maintainers

Changes to this file require a public pull request with rationale. A maintainer being removed should be given an opportunity to respond unless the change is required for immediate security protection.
