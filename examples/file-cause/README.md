# File-cause example

`check.sh` succeeds only when `config.txt` contains `mode=good`. The two
fixture files make the good/bad workspaces differ by one supported workspace
file. A `PROVEN` result therefore means that this file difference passed the
forward and reverse experiments for this oracle and model.

The result is not a general filesystem, kernel, network, or source-history
claim. Review the evidence boundaries in the report. See
[`../../docs/proof-boundary.md`](../../docs/proof-boundary.md).
