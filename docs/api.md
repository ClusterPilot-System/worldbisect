# API guide

The authoritative HTTP contract is `api/openapi.yaml`.

## Authentication

Except for `/api/v1/health`, endpoints require:

```text
Authorization: Bearer <opaque-token>
```

The raw token is generated by `worldbisectd init` and displayed once. Configuration stores only a SHA-256 token hash. Token comparisons are constant-time.

Scopes:

| Scope | Operations |
| --- | --- |
| `read` | Read captures, analyses, jobs, version, metrics, and dashboard data |
| `capture:write` | Queue remote capture jobs |
| `analysis:write` | Queue analysis jobs |
| `admin` | Administrative operations |

## Idempotency

Mutating endpoints require an `Idempotency-Key` header. A key is bound to the authenticated principal, route, and canonical request digest. Reuse with a different payload returns `409 Conflict`.

## Errors

Errors use:

```json
{
  "error": {
    "code": "stable_machine_code",
    "message": "human-readable summary",
    "request_id": "req_...",
    "details": {}
  }
}
```

Do not parse human-readable messages for automation.

## Quotas

The daemon enforces request-size, session, workspace-file, workspace-byte, output, factor, experiment, worker, retry, and timeout limits. Quota exhaustion returns `429` or a terminal failed job with structured diagnostics.

## Remote execution

Remote execution is disabled by default. Enabling it requires:

- canonical absolute executable paths in `allowed_commands`;
- canonical permitted directories in `allowed_working_directories`;
- a token with the required write scope;
- a valid idempotency key;
- all configured quotas to pass.

Authorization binds the opened executable and working directory to the actual child process. A different path, symlink target, hardlink, or modified inode is rejected.

## Tracing

The server accepts and returns W3C `traceparent`. Structured spans are appended to the configured trace file. Trace data is local and no telemetry is exported automatically.
