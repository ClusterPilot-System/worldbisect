# Support

WorldBisect is a community-maintained open-source project.

## Supported requests

Public GitHub issues may be used for:

- reproducible defects;
- documented Linux compatibility problems;
- incorrect diagnostics;
- performance regressions;
- documentation corrections.

Security vulnerabilities and sensitive proof-integrity failures must use GitHub private vulnerability reporting.

## Required information

Include the WorldBisect version, Linux distribution, kernel, architecture, exact sanitized command, oracle, and minimal reproduction. Remove credentials, personal data, private traces, customer information, and proprietary files.

## Not provided

The project does not promise:

- individual debugging or consulting;
- support for undocumented platforms;
- recovery of secrets or private data;
- automatic code repairs;
- universal causal completeness;
- service-level agreements.

Commercial support, if offered by third parties, is independent of the open-source project and does not change Apache-2.0 rights.
