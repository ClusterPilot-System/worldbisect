# Code of Conduct

## Our pledge

We are committed to providing a professional, harassment-free environment for everyone participating in WorldBisect, regardless of experience, identity, background, or role.

## Expected behavior

- Be precise, constructive, and respectful.
- Focus criticism on technical claims, evidence, and code.
- Protect private captures, credentials, customer information, and security reports.
- Disclose conflicts of interest and code provenance.
- Accept that proof-integrity and security changes require conservative review.

## Unacceptable behavior

- Harassment, discrimination, threats, or personal attacks.
- Publishing secrets, personal data, private traces, or embargoed vulnerabilities.
- Knowingly submitting plagiarized, incompatible, or undisclosed third-party code.
- Misrepresenting correlation, model output, or incomplete experiments as a causal proof.

## Enforcement

Maintainers may edit or remove content, reject contributions, temporarily restrict participation, or permanently ban contributors when necessary to protect the project and its community.

Report conduct concerns privately through GitHub private vulnerability reporting when confidentiality is required. For non-sensitive conduct concerns, contact a maintainer listed in `MAINTAINERS.md`.

Enforcement decisions should be documented, proportionate, and handled with appropriate confidentiality.
